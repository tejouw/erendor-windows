# Erendor Online — Windows

Erendor Online'ın Windows sürümü. Oyun kodu bu depoda değildir; burada yalnız indirme dosyası durur.

**İndir:** [ErendorOnline-Windows.zip](https://github.com/tejouw/erendor-windows/releases/latest/download/ErendorOnline-Windows.zip)

1. Zip'i bir klasöre çıkar.
2. `ErendorOnline.exe`'yi çalıştır. Windows "tanınmayan uygulama" uyarısı verirse **Ek bilgi → Yine de çalıştır**.
3. Google hesabınla gir. Telefonda Play Games ya da misafir hesabıyla oynuyorsan önce oyunda **Hesabı Bağla** ile Google hesabını bağla; böylece bilgisayarda aynı karakterlerle oynarsın.

Site: https://erendoronline.com · Android: [Google Play](https://play.google.com/store/apps/details?id=com.erendor.online) · iOS çok yakında
